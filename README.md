# Airplane Game em C#

Projeto desenvolvido em C# utilizando Programação Orientada a Objetos (POO), simulando um jogo de avião.

## Funcionalidades

* Controle da nave
* Sistema de tiros
* Sistema de pontuação
* Inimigos gerados aleatoriamente

## Tecnologias

* C#
* Visual Studio
